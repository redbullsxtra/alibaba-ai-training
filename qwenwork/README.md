# QwenWork Labs

Product labs for the QwenWork workspace track. Same format as the WonderClip labs under `wonderclip/`.

## Prerequisites

Before running any lab, you need a QwenWork account:

1. **Sign up** at [qwenwork.ai](https://qwenwork.ai/) — free to start, browser or desktop.
2. **Subscription cost (checked 2026-10-30):**
   | Plan | Price | Credits |
   |---|---|---|
   | Free | $0 | 500 signup + 200/day |
   | Plus | $20/mo | 2,000/mo |
   | Pro | $40/mo | 4,500/mo |
   The Free tier is sufficient for `lab1-analytics` (it needs file upload + code execution; heavy analytics may draw on the daily credits).
3. Clone this repo locally so you can upload the lab assets.
