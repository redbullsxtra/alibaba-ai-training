# WonderClip Labs

Product labs for the WonderClip video track. Same format as the QwenWork labs under `qwenwork/`.

## Prerequisites

Before running any lab, you need a WonderClip account:

1. **Sign up** at [wonderclip.ai](https://wonderclip.ai/).
2. **Subscription cost (checked 2026-10-30):**
   | Plan | Price | Notes |
   |---|---|---|
   | Basic | $18/mo | Credit top-up only — **cannot run Wan 3.0 Prime** |
   | Standard | $340/mo | Supports Wan 3.0 Prime |
   | Pro | $3,200/mo | Supports Wan 3.0 Prime |
   | Ultimate | $9,000/mo | Supports Wan 3.0 Prime |
3. `lab1-canvas` uses **Wan 3.0 Prime**, so it requires the **Standard plan or higher**. Budget accordingly before the session.
4. Renders consume credits — the generate button shows the cost per run (~29.6 credits for Wan 3.0 Prime / 5s at 480P).
5. Clone this repo locally so you can upload `glass.pptx` from `lab1-canvas/`.
